Project 01
Agentic Multi-Document RAG System
Self-directed · 2026
GitHub ↗

A production-grade agentic RAG pipeline built with LangGraph that intelligently routes each query to the most appropriate retrieval strategy — document search, web search, LLM knowledge, or cache — using a structured LLM classifier.

  • 9-node LangGraph pipeline with an LLM classifier routing queries to four distinct retrieval strategies.
  • Hybrid retrieval combining dense (Qdrant MMR) and sparse (BM25) search, merged via Reciprocal Rank Fusion with cross-encoder reranking (BAAI/bge-reranker-large).
  • Self-correction loop: low-confidence retrievals trigger query rewriting and retry; insufficient context falls back to live web search.

Project 02
VisioNiX  — team project · published
Full-stack AI platform · VDI-Z Journal 2026
GitHub ↗

A full-stack multimodal AI platform that analyses uploaded images using computer vision models and enables multi-turn natural language conversations about visual content via a locally-hosted LLM.

  • Image analysis pipeline using YOLOv8, BLIP, CLIP, and OCR with multi-turn conversational Q&A grounded in visual content (Ollama, locally-hosted).
  • Browser-driven YOLOv8 fine-tuning pipeline running background training jobs with automated mAP50 evaluation and quality-gated deployment.
  • Automated post-training flow: models passing evaluation are uploaded to Hugging Face Hub and published as live inference endpoints.

Project 03
Customer Churn Prediction
Self-directed · 2026
GitHub ↗

An end-to-end telecom churn prediction system with a scikit-learn ML pipeline, a FastAPI backend with business-rule validation, and a Streamlit frontend with dynamic form constraints.

  • Scikit-learn pipeline with stratified splits, MinMaxScaler, and one-hot encoding — preventing training/inference mismatch by design.
  • FastAPI backend with Pydantic schema validation, enum-constrained inputs, and cross-field business-rule checks before prediction.
  • Streamlit frontend with dynamic input constraints displaying churn probability, predicted class, and model confidence in real time.
