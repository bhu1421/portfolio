Project 01

Agentic Multi-Document RAG System

Self-directed · 2026
View on GitHub ↗
  • Designed a 9-node LangGraph pipeline routing queries to document search, web search, LLM knowledge, or cache — using an LLM classifier with structured output, achieving 100% routing accuracy on a 20-question benchmark at 0.18s average latency.
  • Built a hybrid retrieval layer combining dense (Qdrant MMR) and sparse (BM25) search merged via Reciprocal Rank Fusion, with parent-document expansion and cross-encoder reranking (BAAI/bge-reranker-large) for precision.
  • Implemented a self-correction loop: low-confidence retrievals trigger automatic query rewriting and retry; insufficient context falls back to live web search with retry limits to prevent infinite loops.

Project 02

VisioNiX — team project

Full-stack AI platform · Published, VDI-Z 2026
View on GitHub ↗
  • Team-built a full-stack multimodal AI platform analyzing uploaded images with YOLOv8, BLIP, CLIP, and OCR, enabling multi-turn conversations about visual content via a locally-hosted LLM (Ollama).
  • Built the image-grounded conversational chat feature — multi-turn Q&A where the LLM answers based entirely on the visual content of the uploaded image.
  • Built a browser-driven YOLOv8 fine-tuning pipeline running training jobs in background, auto-evaluating model accuracy (mAP50) against a configurable threshold and blocking underperforming deployments.
  • Automated post-training deployment: models passing the quality gate upload to Hugging Face Hub and publish as live inference endpoints, instantly selectable in chat.
